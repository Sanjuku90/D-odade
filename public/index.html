Questions fréquentes

Comment fonctionne le système de quêtes ? +

Toutes les 2 semaines, 3 quêtes simples sont disponibles : partager sur les réseaux sociaux, regarder une vidéo promotionnelle, et d'autres tâches rapides. Chaque quête complétée vous rapporte 45% de votre dépôt initial.

Comment effectuer un dépôt ? +

Les dépôts se font en USDT (TRC20). Après inscription, vous recevrez une adresse de dépôt unique. Envoyez vos fonds, soumettez le hash de transaction, et votre compte sera crédité après validation.

Combien de temps pour recevoir mes gains ? +

Les gains sont crédités instantanément sur votre compte après chaque quête. Un retrait est disponible une fois par cycle de 2 semaines.

Y a-t-il des frais cachés ? +

Non, QuestInvest est 100% transparent. Aucun frais sur les dépôts, aucun frais de gestion. Seuls les frais réseau blockchain standard s'appliquent lors des retraits.
